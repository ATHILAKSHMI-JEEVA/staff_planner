# Teacher Absence Manager — Backend

Node.js + Express + MongoDB REST API.

## Quick Start

1. npm install
2. Make sure MongoDB is running locally
3. npm run seed   (populates test data once)
4. npm run dev    (starts server on port 5000)

Server: http://localhost:5000/api/v1
